# Kyrylo Karmazin — Portfolio

Personal portfolio website built with React and TypeScript.

Live: [kirillkrm.github.io/portfolio](https://kirillkrm.github.io/portfolio)

## Stack

- React 18 + TypeScript
- Tailwind CSS
- Framer Motion
- GitHub Pages

## Development

```bash
npm install
npm start
```

## Deployment

```bash
npm run deploy
```
