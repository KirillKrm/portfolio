# Kyrylo Karmazin — Portfolio

Personal portfolio website built with React and TypeScript.

Live: [kirillkrm.github.io/portfolio](https://kirillkrm.github.io/portfolio)

## Stack

- React 19 + TypeScript 6
- Vite 8 + Vitest
- Tailwind CSS 4
- Framer Motion 12
- GitHub Pages

## Development

```bash
npm install
npm start
```

## Testing

```bash
npm test
```

## Deployment

```bash
npm run deploy
```
